# Sistema de Gestão de Estoque | Inventory Management System

## 🇧🇷 Português

### Sobre o projeto

Este projeto consiste em um sistema de gestão de estoque desenvolvido no Google Sheets, com o objetivo de organizar produtos, registrar movimentações e acompanhar os níveis de estoque de forma simples e automatizada.

A solução utiliza fórmulas, indicadores e formatação condicional para facilitar o controle de entradas, saídas e necessidades de reposição.

### Objetivos

- Organizar o cadastro de produtos.
- Registrar entradas e saídas de mercadorias.
- Calcular automaticamente o estoque atual.
- Definir níveis mínimos de estoque.
- Identificar produtos que precisam de reposição.
- Apresentar indicadores gerenciais em um dashboard.

### Estrutura da planilha

| Aba | Descrição |
|---|---|
| `PRODUTOS` | Cadastro de produtos, categorias, fornecedores, custos, preços e estoque mínimo. |
| `MOVIMENTAÇÕES` | Registro de entradas e saídas de produtos. |
| `ESTOQUE` | Cálculo do saldo atual e identificação de produtos que precisam de reposição. |
| `DASHBOARD` | Indicadores de estoque para acompanhamento gerencial. |

### Funcionalidades

- Cadastro organizado de produtos.
- Registro de movimentações de estoque.
- Cálculo automático das entradas e saídas.
- Atualização do saldo disponível.
- Alertas de estoque mínimo.
- Formatação condicional para destacar situações de reposição.
- Indicadores de gestão.
- Gráfico de comparação do estoque por produto.

### Tecnologias e recursos

- Google Sheets
- Fórmulas de planilha
- `SE`
- `PROCV`
- `SOMASES`
- `CONT.VALORES`
- `CONT.SE`
- `SOMA`
- Formatação condicional
- Gráficos e dashboards

### Indicadores do dashboard

- Total de produtos cadastrados.
- Quantidade total de unidades em estoque.
- Número de produtos que precisam de reposição.
- Total de unidades registradas como saída.

### Resultados esperados

O sistema permite visualizar os níveis de estoque, acompanhar as movimentações e identificar produtos que atingiram ou ultrapassaram o limite mínimo definido.

Os dados de demonstração podem ser substituídos por informações reais de uma empresa.

### Aplicações práticas

Este projeto pode ser adaptado para pequenos comércios, papelarias, lojas de informática, estoques domésticos e pequenos negócios que precisam de um controle organizado de mercadorias.

### Possíveis melhorias futuras

- Inclusão de códigos de barras.
- Registro de usuários responsáveis pelas movimentações.
- Cálculo do valor financeiro total do estoque.
- Relatórios mensais de entradas e saídas.
- Indicadores de giro de estoque.
- Automatizações adicionais com Google Apps Script.

## 🇺🇸 English

### About the Project

This project is an inventory management system built with Google Sheets to organize products, track inventory movements, and monitor stock levels through automated calculations.

The solution uses spreadsheet formulas, dashboard metrics, and conditional formatting to simplify inventory control and identify products that need replenishment.

### Objectives

- Organize product records.
- Track incoming and outgoing inventory.
- Automatically calculate current stock levels.
- Define minimum stock thresholds.
- Identify products that require replenishment.
- Display management metrics in a dashboard.

### Spreadsheet Structure

| Sheet | Description |
|---|---|
| `PRODUTOS` | Product catalog, categories, suppliers, costs, prices, and minimum stock levels. |
| `MOVIMENTAÇÕES` | Records of incoming and outgoing inventory. |
| `ESTOQUE` | Current stock calculations and replenishment alerts. |
| `DASHBOARD` | Inventory metrics for management monitoring. |

### Features

- Organized product catalog.
- Inventory movement tracking.
- Automatic calculation of incoming and outgoing quantities.
- Real-time stock balance updates.
- Minimum stock alerts.
- Conditional formatting for replenishment warnings.
- Inventory management metrics.
- Product stock comparison chart.

### Technologies and Tools

- Google Sheets
- Spreadsheet formulas
- `IF`
- `VLOOKUP`
- `SUMIFS`
- `COUNTA`
- `COUNTIF`
- `SUM`
- Conditional formatting
- Charts and dashboards

### Dashboard Metrics

- Total registered products.
- Total units currently in stock.
- Number of products requiring replenishment.
- Total units recorded as outgoing inventory.

### Expected Results

The system provides a clear overview of inventory levels, tracks stock movements, and identifies products that have reached or fallen below their defined minimum stock thresholds.

Sample data can be replaced with real business information.

### Practical Applications

This project can be adapted for small retailers, stationery stores, computer shops, home inventory management, and small businesses that need a structured inventory tracking solution.

### Future Improvements

- Barcode integration.
- User identification for inventory movements.
- Total inventory valuation.
- Monthly inventory movement reports.
- Inventory turnover metrics.
- Additional automation using Google Apps Script.
